# Task 12 – Power BI Data Transformation using Power Query

## Internship Task: Data Analyst

### Objective
The goal of this task is to clean, transform, and prepare raw data using **Power Query** in Power BI and create basic visualizations.

---

## Dataset Used
- HR Analytics Dataset (`HR_comma_sep.csv`)

---

## Tools Used
- Power BI Desktop
- Power Query Editor

---

## Data Transformation Steps
1. Imported the HR Analytics dataset into Power BI
2. Removed unnecessary columns
3. Renamed column headers for better readability
4. Checked and corrected data types
5. Handled missing and invalid values
6. Created conditional columns:
   - Age Group
   - Salary Band
7. Applied transformations and loaded data into the model

---

## Visualizations Created
- Employees by Department
- Employee Attrition Count
- Distribution based on Salary Band / Age Group
